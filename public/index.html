Read before enabling

WhiteDreams will force-close every running IDM window before each job, then launch its own IDM instance and wait for it to finish. Do not enable this while IDM has downloads in progress or if you plan to start downloads manually in IDM. Closing IDM mid-download can corrupt its queue.

CLOAKBROWSER SETUP

Connect CloakBrowser for file-page links.

FREE LICENSE

Get your CloakBrowser license key

Sign in with GitHub. The license key is sent to the email address connected to your account.

cloakbrowser.dev/free/

  1. 1
    Get your key

    Open the license page, sign in with GitHub, then check your email.

  2. 2
    Open Browser connection

    Go to Settings → Browser connection → CloakBrowser license key.

  3. 3
    Paste and save

    Paste the key and choose Save changes. If saving fails once, retry; if it continues, contact the developer.

Set up the key before resolving a file page

Direct file URLs do not need CloakBrowser. The key is required only for supported page-resolution workflows.

First-use note: CloakBrowser may download its Chromium runtime automatically. This happens once and can use roughly 500 MB or more.
